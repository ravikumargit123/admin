# Baapstore Next.js Showcase

This repository hosts a lightweight **Next.js 14** project that recreates the look and feel of the Baapstore demo storefront at [demo.baapstore.com/a/](https://demo.baapstore.com/a/). Use it as a starting point for building your own white-label ecommerce experience with familiar Baapstore-inspired styling.

## Getting started

1. Install dependencies
   ```bash
   yarn install
   ```
2. Run the development server
   ```bash
   yarn dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view the site.

## What you get

- A gradient-rich hero with calls to action pointing to the live Baapstore demo
- Tailwind CSS styling with Baapstore-inspired purple, pink, and gold accents
- Components for feature highlights, launch steps, and testimonials that you can adapt to your own products or categories

## Deploying

The project works out of the box on platforms that support Next.js (e.g., Vercel or Netlify). Build with:
```bash
yarn build
```
Then start the production server with:
```bash
yarn start
```
